# Android Basics with Compose — лабораторные работы

Решения сгруппированы по согласованной структуре: один проект на юниты 1 и 2, отдельная лабораторная на каждый pathway юнитов 3 и 4. Каждый Android-проект внутри лабораторной самостоятельный и открывается отдельно в Android Studio.

| Лабораторная | Материал курса | Проекты |
|---|---|---|
| [1. Первое приложение](lab-01-first-android-app/README.md) | Unit 1 | First app |
| [2. Интерфейс и состояние](lab-02-building-app-ui/README.md) | Unit 2 | Dice Roller, Lemonade, Tip Time / Art Space |
| [3. Основы Kotlin](lab-03-more-kotlin-fundamentals/README.md) | Unit 3, pathway 1 | Kotlin fundamentals, Kotlin practice |
| [4. Списки](lab-04-scrollable-lists/README.md) | Unit 3, pathway 2 | Affirmations, Courses grid |
| [5. Material Design](lab-05-material-design/README.md) | Unit 3, pathway 3 | Woof, Superheroes, 30 Days |
| [6. Архитектура](lab-06-architecture-components/README.md) | Unit 4, pathway 1 | Unscramble, Dessert Clicker |
| [7. Навигация](lab-07-navigation/README.md) | Unit 4, pathway 2 | Cupcake, Lunch Tray |
| [8. Адаптивные интерфейсы](lab-08-adaptive-layouts/README.md) | Unit 4, pathway 3 | Reply, Sports, My City |

Исходные материалы курса: [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course).
