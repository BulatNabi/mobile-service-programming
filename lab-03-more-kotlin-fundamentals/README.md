# Лабораторная 3 — дополнительные основы Kotlin

Юнит 3, pathway 1: классы, коллекции, обобщения и функции высшего порядка.

`kotlin-fundamentals` содержит упражнения по Kotlin; `kotlin-practice` — codelab-примеры классов, generics, коллекций и функций высшего порядка. Kotlin-примеры без Android запускаются из Android Studio как отдельные Gradle-проекты.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
