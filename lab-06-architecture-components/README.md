# Лабораторная 6 — архитектурные компоненты

Юнит 4, pathway 1: lifecycle, ViewModel, UI state и StateFlow.

`unscramble` — игра со словом и ViewModel; `dessert-clicker-lifecycle` показывает lifecycle Activity и сохранение состояния; `dessert-clicker-viewmodel` переносит состояние кликера во ViewModel.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
