# Лабораторная 1 — первое приложение Android

Юнит 1: основы Kotlin, настройка Android Studio, Jetpack Compose и первый интерфейс.

Приложение с переключаемыми экранами Greeting, Birthday Card, Article, Task Manager, Compose Quadrant и Business Card. Демонстрирует базовые composable-функции и компоновки. В `first-app/app/src/main/java/com/example/unit1/KotlinIntroExamples.kt` добавлены короткие Kotlin-примеры с переменными, выводом, функциями и параметрами.

## Подготовка Android Studio

Установите Android Studio, создайте виртуальное устройство через Device Manager, откройте `first-app` как Gradle-проект и запустите конфигурацию `app`. Это покрывает практические шаги pathway 2; запуск эмулятора зависит от локальной установки Android Studio.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
