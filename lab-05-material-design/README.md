# Лабораторная 5 — Material Design

Юнит 3, pathway 3: темы, типографика, анимации и доступность.

`woof` демонстрирует Material-тему и раскрывающиеся карточки; `superheroes` — оформленный список героев; `thirty-days` — приложение с карточками 30-дневного плана.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
