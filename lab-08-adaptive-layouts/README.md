# Лабораторная 8 — адаптивные интерфейсы

Юнит 4, pathway 3: разные размеры экрана, list-detail и adaptive navigation.

`reply` демонстрирует почтовый интерфейс для compact/medium/expanded; `sports` — адаптивный список и детали; `my-city` — городской гид с архитектурой и адаптивной раскладкой.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
