# Лабораторная 2 — интерфейс и состояние

Юнит 2: интерактивность, ввод данных, состояние и обработка нажатий.

Проекты: `dice-roller` — приложение с кнопкой и броском кубика; `lemonade` — пошаговый сценарий с кликабельным изображением и состоянием; `tip-time-and-art-space` — переключаемые экраны Tip Time и Art Space. Kotlin-практика по условиям, nullable-типам, классам и lambda находится в `KotlinFundamentalsExamples.kt`. Каждый проект запускается отдельно.

## Запуск

Откройте папку нужного проекта внутри этой лабораторной в Android Studio и дождитесь синхронизации Gradle. Для запуска выберите конфигурацию `app` и эмулятор или подключённое устройство. Для Kotlin-проектов без Android используйте Gradle-конфигурацию проекта.
